# Getting help

Welcome, and thank you for using homebox-clipper! Here is where to go for what.

| You want to... | Go to |
|----------------|-------|
| Ask how to use or set up the extension | [Discussions, Q&A](https://github.com/Foufou-exe/homebox-clipper/discussions/categories/q-a) |
| Share an idea or suggest an improvement | [Discussions, Ideas](https://github.com/Foufou-exe/homebox-clipper/discussions/categories/ideas) |
| Show how you use it, or chat | [Show and tell](https://github.com/Foufou-exe/homebox-clipper/discussions/categories/show-and-tell) or [General](https://github.com/Foufou-exe/homebox-clipper/discussions/categories/general) |
| Report a bug you can reproduce | [Bug report](https://github.com/Foufou-exe/homebox-clipper/issues/new?template=bug.yml) |
| Report a misdetected store page | [Merchant detection](https://github.com/Foufou-exe/homebox-clipper/issues/new?template=merchant-detection.yml) |
| Ask for a new store | [Merchant request](https://github.com/Foufou-exe/homebox-clipper/issues/new?template=merchant-request.yml) (see [MERCHANTS.md](MERCHANTS.md)) |
| Report a security problem | [SECURITY.md](SECURITY.md), never in public |
| Ask about HomeBox itself | [HomeBox documentation](https://homebox.software) |

## Before you ask

- The [Troubleshooting and FAQ](https://github.com/Foufou-exe/homebox-clipper/wiki/Troubleshooting-and-FAQ) wiki page lists every error message of the extension with its fix.
- The [wiki](https://github.com/Foufou-exe/homebox-clipper/wiki/Home) covers installation, configuration and usage.
- Search the existing discussions and issues: your question may already have an answer.

## Privacy

Never post API keys, real instance addresses (public or local), order numbers, raw store pages or personal data, in discussions or in issues. Describe the problem in your own words or blur your screenshots.

## Response times

homebox-clipper is maintained by one person in their spare time. There is no guaranteed response time and no support contract: replies may take days or weeks. Questions that are clear, searchable and free of personal data are the easiest to answer, and community members are welcome to help each other. Security reports follow the response time given in [SECURITY.md](SECURITY.md).

Please be kind: see the [Code of Conduct](CODE_OF_CONDUCT.md).
