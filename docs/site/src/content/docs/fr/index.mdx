**HomeBox Clipper** est une extension de navigateur pour Chrome et Firefox (Manifest V3) qui transforme un achat en
ligne en objet d'inventaire [HomeBox](https://github.com/sysadminsmedia/homebox), facture PDF comprise, après votre
confirmation. Elle fonctionne actuellement avec **Amazon** (la page « Détails de la commande ») : Amazon.fr, ainsi que
Amazon.de, .es, .it, .com.be, .nl, .co.uk et .com en test (voir [Marchands pris en charge](/homebox-clipper/fr/supported-merchants/)), et
ne communique qu'avec **votre** instance HomeBox auto-hébergée (API testée avec la v0.27).

> [!NOTE]
> Le projet est un MVP. Il est indépendant : il n'a aucun lien avec Amazon ni avec l'équipe de HomeBox.

<CardGrid>
  <Card title="Vos données restent les vôtres" icon="approve-check">
    L'extension ne communique qu'avec la page du marchand que vous consultez et avec votre propre instance HomeBox.
    Aucune analyse d'usage, aucun serveur tiers.
  </Card>
  <Card title="Rien n'est écrit sans vous" icon="pencil">
    Chaque import affiche un écran de confirmation : vous vérifiez, modifiez ou décochez chaque valeur avant que
    quoi que ce soit ne soit créé dans HomeBox.
  </Card>
  <Card title="Facture comprise" icon="document">
    La facture PDF, la photo du produit et la garantie sont jointes à l'objet lorsque le marchand les
    fournit.
  </Card>
  <Card title="Chrome et Firefox" icon="puzzle">
    Une seule extension, Manifest V3, pour Chrome (et les navigateurs Chromium) et Firefox 140 ou ultérieur.
  </Card>
</CardGrid>
