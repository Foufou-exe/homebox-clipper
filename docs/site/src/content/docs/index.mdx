**HomeBox Clipper** is a browser extension for Chrome and Firefox (Manifest V3) that turns an online purchase into an
[HomeBox](https://github.com/sysadminsmedia/homebox) inventory item, PDF invoice included, after your
confirmation. It currently works with **Amazon** (the "Order Details" page): Amazon.fr, plus Amazon.de,
.es, .it, .com.be, .nl, .co.uk and .com in testing (see [Supported merchants](/homebox-clipper/supported-merchants/)), and
talks only to **your** self-hosted HomeBox instance (API tested with v0.27).

:::note
The project is an MVP. It is independent: it has no affiliation with Amazon or the HomeBox team.
:::

<CardGrid>
  <Card title="Your data stays yours" icon="approve-check">
    The extension talks only to the merchant page you are on and to your own HomeBox instance. No
    analytics, no third-party server.
  </Card>
  <Card title="Nothing is written without you" icon="pencil">
    Every import shows a confirmation screen: you review, change or untick each value before anything is
    created in HomeBox.
  </Card>
  <Card title="Invoice included" icon="document">
    The PDF invoice, the product photo and the warranty are attached to the item when the merchant
    provides them.
  </Card>
  <Card title="Chrome and Firefox" icon="puzzle">
    One extension, Manifest V3, for Chrome (and Chromium browsers) and Firefox 140 or later.
  </Card>
</CardGrid>
